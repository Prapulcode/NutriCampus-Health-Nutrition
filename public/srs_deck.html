System Scope Specification
In-Scope Deliverables (Version 1.0 Release):
  • 50-25-25 visual balanced meal guidance system
  • Campus canteen and hostel food alternative database
  • Metric/Imperial anthropometric BMI screening module
  • Daily hydration tracker with 5.0 Liter safety ceiling
  • Interactive 7-item nutrition myth-busting quiz
  • Phase 6 community usability feedback portal
Out-of-Scope Exclusions (System Boundaries):
  • No clinical medical diagnosis or therapeutic prescription regimens
  • No calorie counting or restrictive dietary prescription models
  • No hardware sensors or wearable biometric synchronization

  • Programming Lab Students: Managing digital eye strain (20-20-20 rule) and hydration.

  • Peer Review Cohort: 12+ CSE students testing usability and habit retention.
  • Faculty Evaluators: Reviewing Design Thinking adherence and syllabus compliance.
Deployment Environment:

Universal web browsers: Chrome, Edge, Safari across mobile and desktop devices.

System Architecture & Functional Requirements

03 / 05
Architectural Framework & Data Flow
Tier 1: Client Presentation Layer Responsive Single-Page Web Application built with HTML5, CSS3, and ES6+.
Tier 2: Business Logic & Controllers Client-side Quetelet BMI computation, 5L fluid clamping, and instant quiz feedback.
Tier 3: Dual-Mode Persistence • Browser localStorage for zero-latency offline hydration logs and theme state.
• Python/Flask REST API and SQLite (health_nutrition.db) for survey aggregation.

✓ Operates completely standalone without active internet; synchronizes when connected.

Core Functional Specifications
  • FR-1: 50-25-25 Balanced Plate Guide: Interactive meal ratio guide: 50% fiber/vegetables, 25% complex carbs, 25% protein.
  • FR-2: Campus Canteen Food Swaps: Nutritional alternatives replacing instant noodles, packaged sodas, and fried snacks.
  • FR-3: Anthropometric BMI Calculator: Metric/Imperial Quetelet ratio screening tool with visual gauge and medical disclaimer.
  • FR-4: Daily Hydration Tracker (5.0 L Limit): Fluid intake simulation with strict 5000 mL daily safety ceiling preventing hyponatremia.
  • FR-5: Myth-Busting Quiz & Usability Portal: Gamified educational quiz with instant scientific rationales and rating-free peer feedback.

Non-Functional Requirements & Constraints

04 / 05
Quality Standards & System Security
Performance Benchmarks:
  • Page load latency under 1.5 seconds on standard mobile connections
  • Lightweight bundle size under 150 KB total uncompressed footprint
  • Real-time client computational latency under 16 milliseconds
  • Zero external CSS/JS framework dependencies
Security & Privacy Protocols:
  • Zero mandatory personal information collection (privacy by design)
  • No authentication requirements or user account storage
  • Parameterized SQL queries eliminating SQL injection risks
  • Strict DOM text sanitization preventing Cross-Site Scripting (XSS)
System Constraints & Medical Ethics
Technical & Platform Constraints:
  • Cross-browser compatibility (Chrome, Safari, Edge, Firefox)
  • Responsive layout scaling across 360px mobile to 4K desktop monitors
  • Dual execution: zero-dependency local Python server and cloud Vercel edge
Mandatory Medical Ethics Boundary:
  • Strictly defined as an educational awareness and screening platform
  • BMI defined strictly as an anthropometric ratio, not clinical diagnosis
  • Prominent non-diagnostic medical disclaimers displayed on screening views
  • Hydration tracking programmatically capped at 5.0 Liters for physical safety
